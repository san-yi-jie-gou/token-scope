## 宣传文本

一个面板看清所有 Coding Agent 的 Token 消耗。自动识别本地日志，按天与按月统计，默认排除缓存；桌面组件、菜单栏和系统 Widget 始终同步。

## 描述

你在 Codex、Claude Code、Kimi Code、Cursor 等多个 Coding Agent 之间切换，却很难回答一个简单问题：今天到底用了多少 Token？

TokenScope 将散落在本机的用量记录汇总成一个安静、清晰的 macOS 桌面面板。无需登录，也无需填写 API Key；授权个人主目录后，即可查看今天与本月的真实消耗。

一眼看清用量

• 自动识别 Codex、Claude Code、CC Switch、Kimi Code、Oh My Pi、OpenCode、Gemini CLI、GitHub Copilot、Cursor、Qoder、Windsurf、Cline 与 Trae
• 只显示当前统计周期内实际有数据的 Agent
• 分开显示输入、输出与缓存 Token
• 默认排除缓存，避免缓存命中放大总消耗；需要时可随时纳入
• 月视图按天展示用量与峰值，变化趋势一目了然

融入 macOS 桌面

• 左键点击菜单栏图标即可显示或隐藏桌面组件
• 桌面组件、菜单栏设置与系统 Widget 保持同步
• WidgetKit 小组件可添加到桌面和通知中心
• 每五分钟自动刷新，也可手动刷新
• 支持登录时启动和窗口置顶

隐私优先

所有统计均在本机完成。TokenScope 只读取受支持 Coding Agent 日志中的时间、模型与 Token 用量字段，不收集、存储或上传提示词、模型回复、API 密钥、OAuth 信息或账号配置。

TokenScope 运行在 App Sandbox 中。主应用与系统 Widget 仅通过 127.0.0.1 交换汇总数据，不连接外部服务器。

系统要求：macOS 14.0 或更高版本。
