## 描述

TokenScope 是一款原生 macOS Token 用量统计工具，帮助你在一个安静、清晰的桌面组件中查看多个 Coding Agent 的本地用量。

支持自动识别 Codex、Claude Code、CC Switch、Kimi Code、Oh My Pi、OpenCode 与 Gemini CLI。TokenScope 只显示当天或本月实际有数据的 Agent，并将输入、输出和缓存 Token 分开统计。

主要功能：

• 今天与本月两种统计视图
• 月视图按天展示 Token 消耗图表
• 默认排除缓存，可随时切换是否包含缓存
• 菜单栏与桌面组件保持同步
• 原生 WidgetKit 小组件，可添加到桌面和通知中心
• 每五分钟自动刷新
• 支持登录时启动和窗口置顶

隐私优先：

TokenScope 在 App Sandbox 中运行。首次启动时，你需要主动授权个人主目录。应用只读取受支持 Coding Agent 的本地用量字段，不收集、存储或上传提示词、模型回复、API 密钥、OAuth 信息或账号配置。主应用与系统 Widget 仅通过 127.0.0.1 交换汇总数据。

系统要求：macOS 14.0 或更高版本。
