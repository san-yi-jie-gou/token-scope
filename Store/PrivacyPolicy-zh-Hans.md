# TokenScope 隐私政策

生效日期：2026 年 7 月 23 日

TokenScope 尊重并保护你的隐私。本政策说明 TokenScope 如何处理数据。

## 数据处理

TokenScope 不收集、不上传、不出售，也不与第三方共享个人数据。

在你明确选择并授权个人主目录后，TokenScope 会在本机读取受支持 Coding Agent 日志中的时间、模型标识和 Token 用量字段，用于生成当天及本月统计。TokenScope 不读取或持久化提示词、模型回复、API 密钥、OAuth 凭据、Cookie 或账号配置。

## 本地权限

TokenScope 使用 macOS App Sandbox。目录访问权限由 macOS 文件选择器授予，并以安全范围书签保存在本机。你可以在 TokenScope 菜单栏图标的右键菜单中更改数据目录，也可以在 macOS 系统设置中撤销相关文件访问权限。

## 系统 Widget

系统 Widget 通过本机回环地址 127.0.0.1 从主应用读取聚合后的 Token 统计。数据不会因此发送到互联网。保持 TokenScope 运行可让 Widget 持续更新。

## 数据保留

TokenScope 不建立云端账号或远程数据库。应用只在本机保存显示偏好、窗口位置和目录授权书签。删除应用及其容器数据会删除这些设置。
