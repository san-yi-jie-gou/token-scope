# TokenScope 支持

## 开始使用

1. 首次启动 TokenScope 时，在系统文件选择器中选择你的个人主目录。
2. TokenScope 会自动识别已安装且在所选统计周期内产生过数据的 Coding Agent。
3. 左键点击菜单栏图标可显示或隐藏桌面组件，右键点击可更改缓存统计、数据目录、置顶和登录启动设置。
4. 在 macOS 桌面或通知中心编辑 Widget，搜索 TokenScope 即可添加系统 Widget。

## Widget 没有数据

请先启动 TokenScope 并完成数据目录授权。系统 Widget 从正在运行的主应用读取本地汇总，每五分钟更新一次。建议开启“登录时启动”。

## 支持范围

当前支持 Codex、Claude Code、CC Switch、Kimi Code、Oh My Pi、OpenCode、Gemini CLI、GitHub Copilot、Cursor、Qoder、Windsurf、Cline 与 Trae。各工具日志格式变化时，TokenScope 可能需要更新解析器；部分工具仅在本地日志包含明确 Token 用量字段时显示。
